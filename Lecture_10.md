# Лекція 10: Ортогональна факторизація (метод обертань Гівенса)

## 1. Теоретична частина

### Альтернатива LU-розкладанню: QR-розкладання
У лекції 4 ми розглядали LU-факторизацію для розв'язання СЛАР. Існує інший, надзвичайно потужний клас методів, що базується на **ортогональній факторизації**, найвідомішим представленням якої є **QR-розкладання**.

При QR-розкладанні матриця `A` представляється у вигляді:
`A = Q * R`
де:
- `R` - **верхня трикутна матриця** (аналогічна матриці `U` в LU-розкладанні).
- `Q` - **ортогональна матриця**.

**Що таке ортогональна матриця?** Це матриця, для якої обернена дорівнює транспонованій: `Q⁻¹ = Qᵀ`. Це її ключова властивість. Операція транспонування є тривіальною для комп'ютера (на відміну від обернення), що робить подальші обчислення дуже зручними та швидкими.

> **Нотатка: Чому QR-розкладання таке важливе?**
>
> Головна перевага ортогональних методів - це їхня **висока обчислювальна стійкість**.
>
> *   **LU-розкладання** можна порівняти з роботою хірурга з дуже гострим скальпелем, але злегка тремтячою рукою. Для більшості операцій все буде добре. Але на дуже складних, "погано обумовлених" матрицях, кожна маленька похибка округлення може накопичуватись і призводити до значних неточностей у фінальному результаті.
> *   **QR-розкладання** - це той самий хірург, але який використовує високоточний роботизований маніпулятор. Кожен крок (обертання) виконується таким чином, щоб не накопичувати похибки. Для критично важливих та складних обчислень цей метод є набагато надійнішим.

### Розв'язання СЛАР за допомогою QR-розкладання
Алгоритм елегантний і простий:
1.  Початкова система: `A*x = b`
2.  Підставляємо розкладання: `(Q*R)*x = b`
3.  Домножуємо обидві частини зліва на `Qᵀ`: `Qᵀ*(Q*R)*x = Qᵀ*b`
4.  Оскільки `Qᵀ*Q = I` (одинична матриця), вона просто "зникає": `R*x = Qᵀ*b`
5.  Тепер ми маємо систему з верхньою трикутною матрицею `R`, яка легко розв'язується **зворотною підстановкою**, як і в методі Гауса.

### Метод обертань Гівенса
Це один з методів для отримання QR-розкладання.
**Стратегія:** Ми будемо послідовно "знищувати" (обнуляти) кожен елемент матриці `A` під головною діагоналлю. Для обнулення одного конкретного елемента `A(i, j)` ми використовуємо спеціальну **матрицю обертання Гівенса `G`**.

Матриця `G` схожа на одиничну, але містить елементи `cos(θ)` та `sin(θ)`, які підібрані так, щоб при множенні `G * A` саме елемент `A(i, j)` перетворився на нуль. Ми послідовно застосовуємо такі матриці обертання `G₁, G₂, ...` для всіх піддіагональних елементів, поки наша початкова матриця `A` не перетвориться на верхню трикутну матрицю `R`.

### Приклад ручного розрахунку: Один крок обертання
**Мета:** Обнулити елемент `A[1,0]` у матриці `A = [[3, 2], [2, 5]]`.
Тут `A[0,0] = 3` (елемент на діагоналі) та `A[1,0] = 2` (елемент, що обнуляємо).

1.  **Розрахунок знаменника `r`:**
    `r = sqrt(A[0,0]² + A[1,0]²) = sqrt(3² + 2²) = sqrt(13) ≈ 3.605`
2.  **Розрахунок коефіцієнтів `c` (косинус) та `s` (синус):**
    `c = A[0,0] / r = 3 / sqrt(13) ≈ 0.832`
    `s = -A[1,0] / r = -2 / sqrt(13) ≈ -0.555`
3.  **Формування матриці обертання Гівенса `G`:**
    `G = [[c, -s], [s, c]] = [[0.832, 0.555], [-0.555, 0.832]]`
4.  **Застосування обертання `R = G * A`:**
    `R = [[0.832, 0.555], [-0.555, 0.832]] * [[3, 2], [2, 5]]`
    `R ≈ [[3.605, 4.440], [0.000, 3.051]]` -> **елемент [1,0] обнулився!**

**Результат:** Ми отримали верхню трикутну матрицю `R`.

## 2. Приклад розрахунку на C#
Код демонструє повний цикл розв'язання `A*x=b` через QR-розкладання методом Гівенса.

```csharp
// Program.cs
using System;
using MathNet.Numerics.LinearAlgebra;

public class Program
{
    public static void Main(string[] args)
    {
        // --- Вхідні дані ---
        var A = Matrix<double>.Build.DenseOfArray(new double[,] {
            { 3, 2, 3 }, { 2, 5, 1 }, { 3, 1, 6 }
        });
        var b = Vector<double>.Build.Dense(new double[] { 14, 12, 16 });

        Console.WriteLine("--- Початкова система A*x = b ---");
        Console.WriteLine("Матриця A:\n" + A.ToMatrixString("F4"));

        // --- QR розкладання методом Гівенса ---
        var R = A.Clone(); // R буде поступово перетворюватись з A у верхню трикутну
        // Q_t - це матриця, в якій ми будемо накопичувати всі обертання.
        // В кінці вона стане рівною Q транспонованій (Q^T).
        var Q_t = Matrix<double>.Build.DenseIdentity(A.RowCount); 

        // Проходимо по кожному стовпцю, щоб обнулити елементи під діагоналлю
        for (int j = 0; j < A.ColumnCount; j++)
        {
            // Проходимо по кожному рядку нижче діагоналі в поточному стовпці
            for (int i = j + 1; i < A.RowCount; i++)
            {
                // Елемент, який потрібно обнулити - R[i, j]
                double elementToZero = R[i, j];
                
                if (Math.Abs(elementToZero) > 1e-12)
                {
                    double diagonalElement = R[j, j];
                    
                    // Розраховуємо c і s для матриці обертання
                    double r = Math.Sqrt(diagonalElement * diagonalElement + elementToZero * elementToZero);
                    double c = diagonalElement / r;
                    double s = -elementToZero / r;
                    
                    // Створюємо матрицю обертання Гівенса G
                    var G = Matrix<double>.Build.DenseIdentity(A.RowCount);
                    G[i, i] = c; G[j, j] = c;
                    G[i, j] = s; G[j, i] = -s;

                    // Застосовуємо обертання до R, щоб обнулити елемент
                    R = G.Multiply(R);
                    // І одночасно застосовуємо це ж обертання до Q_t
                    Q_t = G.Multiply(Q_t);
                }
            }
        }
        
        // --- Розв'язання системи Rx = Q^T*b ---
        // Q_t вже є Q^T, тому просто множимо її на b
        var b_new = Q_t.Multiply(b); 
        // Розв'язуємо систему з верхньою трикутною матрицею R
        var x = R.Solve(b_new); 

        Console.WriteLine("\n--- Результат (метод Гівенса) ---");
        Console.WriteLine("x = " + x.ToVectorString("F4"));

        // --- Перевірка (прямий метод) ---
        var x_direct = A.Solve(b);
        Console.WriteLine("\n--- Результат (прямий метод) ---");
        Console.WriteLine("x = " + x_direct.ToVectorString("F4"));
    }
}
```

### 3. Перевірка правильності обрахунку
1. **Трикутна форма `R`:** Після завершення циклів, матриця `R` має бути верхньою трикутною (всі елементи нижче головної діагоналі мають бути близькими до нуля).
2. **Ортогональність `Q`:** Матриця `Q = Q_t.Transpose()` має бути ортогональною. Перевірте, що `Q.Multiply(Q.Transpose())` є одиничною матрицею.
3. **Кінцевий результат:** Вектор `x` має точно збігатися з результатом, отриманим прямим методом.
