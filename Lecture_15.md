# Лекція 15: Швидкий розчеплений метод потокорозподілу (FDLF - Fast Decoupled Load Flow)

## 1. Теоретична частина

### Метод Стотта-Альсака (FDLF)
У попередніх лекціях ми розглядали метод Ньютона-Рафсона ([Лекція 2](Lecture_2.md)) для розрахунку потокорозподілу, який вимагає на кожній ітерації формування та обернення (або факторизації) Якобіана — великої матриці похідних. 
У реальних високовольтних електричних мережах активний опір ліній ($r$) значно менший за їх реактивний опір ($x$), тому матриця провідностей $Y_{bus}$ переважно уявна. Це призводить до сильного зв'язку між активною потужністю $P$ і кутами напруг $\theta$, та між реактивною потужністю $Q$ і модулями напруг $V$, у той час як перехресні зв'язки ($P-V$ та $Q-\theta$) є відносно слабкими.

Швидкий розчеплений метод (Fast Decoupled Load Flow, запропонований Б. Стоттом і О. Альсаком у 1974 р.) базується на двох припущеннях:
1. Зміни кутів фаз впливають переважно на перетікання активної потужності: $\Delta P \approx \frac{\partial P}{\partial \theta} \Delta \theta$
2. Зміни модулів напруг впливають переважно на реактивну потужність: $\Delta Q \approx \frac{\partial Q}{\partial V} \Delta V$

Тому Якобіан можна **розчепити** (decouple) на дві менші матриці, ігноруючи позадіагональні блоки:
$\begin{bmatrix} \Delta P \\ \Delta Q \end{bmatrix} = \begin{bmatrix} J_{11} & 0 \\ 0 & J_{22} \end{bmatrix} \begin{bmatrix} \Delta \theta \\ \Delta V \end{bmatrix}$

Далі робляться додаткові спрощення мережі (вважаємо $r \approx 0$, $\cos(\theta_{ij}) \approx 1$, $V_i \approx 1$ p.u. при розрахунку елементів матриці), що дозволяє сформувати дві **постійні** матриці $B'$ та $B''$:

$\frac{\Delta P}{V} = B' \cdot \Delta \theta$
$\frac{\Delta Q}{V} = B'' \cdot \Delta V$

> Головна перевага FDLF — матриці $B'$ та $B''$ формуються із уявної частини $Y_{bus}$ (з певними модифікаціями для шунтів/трансформаторів) і **залишаються незмінними** протягом всього розрахунку. Це означає, що їх потрібно факторизувати лише **один раз** перед початком ітерацій. Завдяки цьому кожна ітерація FDLF виконується в 5-10 разів швидше за ітерацію Ньютона-Рафсона. І хоча метод Стотта-Альсака може потребувати більше ітерацій для збіжності, загальний час розв'язання для великих схем (тисячі вузлів) значно менший!

> **Глибока інтуїція: Чому P та Q розчеплюються?**
> Фізична причина цього феномену криється в електромагнітній природі змінного струму. Активна потужність (P) — це робота, що виконується. Вона передається тоді, коли хвиля напруги на одному кінці ЛЕП "випереджає" хвилю на іншому — тобто існує різниця фаз $\theta$. 
> Реактивна потужність (Q) — це енергія магнітних полів, яка лише коливається туди-сюди. Вона тече звідти, де амплітуда напруги $V$ більша, туди, де вона менша. 
> Тому, коли диспетчер збільшує генерацію P, ротори турбін прискорюються і кути $\theta$ миттєво зростають. Але модулі напруг $V$ залишаються майже стабільними. Ця слабка взаємодія (Cross-Coupling) між P і V дозволяє математично розірвати систему на два незалежних маятники: "кутовий" і "амплітудний". Саме ця фізична властивість була блискуче експлуатована Стоттом і Альсаком для прискорення матричних обчислень.

### Приклад ручного розрахунку: Одна ітерація
Розглянемо 3-вузлову систему (вузол 1 — балансуючий, вузли 2 і 3 — навантажувальні).
Нехай матриці $B'$ та $B''$ однакові і дорівнюють взятій зі зворотним знаком уявній частині $Y_{bus}$ (без 1-го рядка і стовпця):
$B' = B'' = \begin{bmatrix} 14 & -4 \\ -4 & 9 \end{bmatrix}$

Поточні значення напруг $V_2 = 1.0, V_3 = 1.0$, кути $\theta_2 = 0, \theta_3 = 0$.
Обчислені нев'язки (місматчі) потужностей:
$\Delta P = [-0.10, -0.05]^T$ (для прикладу)
$\Delta Q = [-0.05, -0.02]^T$

1. **Ітерація активної потужності ($P-\theta$):**
Ділимо $\Delta P$ на $V$: $\Delta P/V = [-0.10/1.0, -0.05/1.0]^T = [-0.10, -0.05]^T$.
Розв'язуємо систему: $B' \cdot \Delta \theta = \Delta P/V$.
Оскільки $B'^{-1} = \begin{bmatrix} 0.0818 & 0.0364 \\ 0.0364 & 0.1273 \end{bmatrix}$, то:
$\Delta \theta = B'^{-1} \cdot \Delta P/V = [-0.01, -0.01]^T$.
Оновлюємо кути: $\theta_{new} = \theta + \Delta \theta$.

2. **Ітерація реактивної потужності ($Q-V$):**
Після оновлення $\theta$ перераховуємо $\Delta Q$ (для простоти беремо початкове), ділимо на $V$: $\Delta Q/V = [-0.05, -0.02]^T$.
Розв'язуємо систему: $B'' \cdot \Delta V = \Delta Q/V$.
$\Delta V = B''^{-1} \cdot \Delta Q/V = [-0.0048, -0.0043]^T$.
Оновлюємо напруги: $V_{new} = V + \Delta V$.

## 2. Приклад розрахунку на C#
Нижче наведено програмну реалізацію алгоритму FDLF для 3-вузлової системи за допомогою `MathNet.Numerics`.

```csharp
// Program.cs
using System;
using MathNet.Numerics.LinearAlgebra;

public class Program
{
    public static void Main(string[] args)
    {
        // 1. Ініціалізація даних системи (в.о.)
        // Вузли 2 і 3 - навантажувальні (PQ)
        double[] P_sch = { -1.0, -0.5 }; // Задані активні потужності
        double[] Q_sch = { -0.5, -0.2 }; // Задані реактивні потужності
        
        // Матриці B' та B''
        var B_prime = Matrix<double>.Build.DenseOfArray(new double[,] {
            { 14, -4 },
            { -4,  9 }
        });
        var B_double_prime = B_prime.Clone();

        // Початкові наближення
        var V = Vector<double>.Build.Dense(new double[] { 1.0, 1.0 }); // Напруги вузлів 2, 3
        var theta = Vector<double>.Build.Dense(new double[] { 0.0, 0.0 }); // Кути вузлів 2, 3
        
        // Напруга балансуючого вузла (вважаємо V1 = 1.0, theta1 = 0)
        double V1 = 1.0;
        double theta1 = 0.0;
        
        // Елементи уявної частини провідностей ліній (зі знаком + як в B')
        double B12 = 10, B13 = 5;
        double B22 = -14, B23 = 4;
        double B32 = 4, B33 = -9;
        
        double tolerance = 1e-4;
        int maxIter = 10;
        int iter = 0;
        bool converged = false;
        
        Console.WriteLine("--- Метод Стотта-Альсака (FDLF) ---");
        
        // Факторизація B' та B'' виконується лише ОДИН РАЗ до початку циклу
        var B_prime_inv = B_prime.Inverse();
        var B_double_prime_inv = B_double_prime.Inverse();
        
        while (iter < maxIter && !converged)
        {
            iter++;
            
            // --- P-theta ітерація (Активна потужність) ---
            double P2_calc = V[0] * V1 * B12 * Math.Sin(theta[0] - theta1) + 
                             V[0] * V[1] * B23 * Math.Sin(theta[0] - theta[1]);
                             
            double P3_calc = V[1] * V1 * B13 * Math.Sin(theta[1] - theta1) + 
                             V[1] * V[0] * B32 * Math.Sin(theta[1] - theta[0]);
                             
            var deltaP = Vector<double>.Build.Dense(new double[] { P_sch[0] - P2_calc, P_sch[1] - P3_calc });
            var deltaP_V = Vector<double>.Build.Dense(new double[] { deltaP[0] / V[0], deltaP[1] / V[1] });
            
            // Знаходимо приріст кутів: dTheta = inv(B') * (dP/V)
            var deltaTheta = B_prime_inv * deltaP_V;
            theta += deltaTheta;
            
            // --- Q-V ітерація (Реактивна потужність) ---
            double Q2_calc = -V[0] * V1 * B12 * Math.Cos(theta[0] - theta1) - 
                              V[0] * V[1] * B23 * Math.Cos(theta[0] - theta[1]) - 
                              V[0] * V[0] * B22;
                              
            double Q3_calc = -V[1] * V1 * B13 * Math.Cos(theta[1] - theta1) - 
                              V[1] * V[0] * B32 * Math.Cos(theta[1] - theta[0]) - 
                              V[1] * V[1] * B33;
                              
            var deltaQ = Vector<double>.Build.Dense(new double[] { Q_sch[0] - Q2_calc, Q_sch[1] - Q3_calc });
            var deltaQ_V = Vector<double>.Build.Dense(new double[] { deltaQ[0] / V[0], deltaQ[1] / V[1] });
            
            // Знаходимо приріст напруг: dV = inv(B'') * (dQ/V)
            var deltaV = B_double_prime_inv * deltaQ_V;
            V += deltaV;
            
            // Умова збіжності
            if (deltaP.InfinityNorm() < tolerance && deltaQ.InfinityNorm() < tolerance)
            {
                converged = true;
            }
        }
        
        Console.WriteLine($"\nКінцевий результат (за {iter} ітерацій):");
        Console.WriteLine("Напруги V2, V3: " + V.ToVectorString("F4"));
        Console.WriteLine("Кути theta2, theta3 (рад): " + theta.ToVectorString("F4"));
    }
}
```
